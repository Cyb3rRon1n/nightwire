# Phone (Play Screen Step 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each player a phone: contacts they've met (plus Saeko's crew and Jun), private texts with replies whose timing and tone come from the contact's role and trust, engine texts when debt or gigs change, contacts who remember what you told them (so a lie can come back), and the approved pop-out phone on screen.

**Architecture:** All phone state is plain JSON-ready dicts on `Session.phone` (per player), so saving needs one line. `engine/phone.py` holds the deterministic rules (contacts, trust, reply delay, tone, delivery, rate limits) with no model calls. `narrator/phone_reply.py` writes a reply's words through the existing structured `judge` call, given a tone tag and the facts allowed. The server gets one new message type, `text`; every action, roll and text advances the player's phone clock and delivers what's due. The view sends each player only their own phone. The screen adds a Phone button and the floating phone from the approved "A + B · Phone popped out" board.

**Tech Stack:** Python 3.11 engine/server (pytest), qwen3:8b via the existing NarratorClient `judge`, Next.js 16 / React 19 play screen (node tests, Playwright dry runs).

**Spec:** `docs/superpowers/specs/2026-11-06-messenger-play-screen-design.md`, section "Phone (step 2)" with the owner's decisions and the relationship model.

## Global Constraints

- The engine owns every number (trust, delay, schedule, who texts first); the model only writes words.
- Roles: family, partner, friend (`close` flag), crew, boss, fixer, creditor, informant, rival, enemy, stranger.
- Trust 0-5 float, shown as an int. Start: stranger 2, enemy 0, family/partner 3, everyone else 2.
- Delay in the player's phone turns: `base(role) + (5 - trust) + pace`, clamped 0-6; base partner 0; family, friend, crew, creditor 1; boss, fixer, informant 2; rival 3; enemy 4 (and an enemy below trust 1 never answers). Pace -1/0/+1 per character. Availability (sleep, work) is NOT in v1: the game has no clock yet; add it with one.
- Tone tags: trust >= 4 `warm`, 3 `friendly`, 2 `curt`, 1 `guarded`, 0 `hostile`; a cold spell (after a discovered lie) forces `guarded`.
- At most one unprompted text per player every 4 phone turns.
- Texts never enter `session.log` as words (the log is shared and feeds the narrator). The narrator only hears "{name} texted someone" as a world event; the referee may note who noticed.
- Starting contacts on join: Saeko Kirigaya (creditor, pace -1), Jun Arakawa (fixer). Calls are out of scope.
- No new dependencies. Run `python -m pytest tests/ -q` and `cd frontend && npm run test:nightwire && npx tsc --noEmit && ./node_modules/.bin/eslint src tests` after every task.

- [ ] **Step 3: Implement** `engine/phone.py`:

```python
"""A player's phone: contacts with role + trust, threads, and the timing rules (docs/superpowers/specs/
2026-11-06-messenger-play-screen-design.md, "Phone"). Plain dicts so Session saves them as JSON. No model calls."""

from engine.session import Session

ROLE_BASE = {"partner": 0, "family": 1, "friend": 1, "crew": 1, "creditor": 1, "boss": 2, "fixer": 2,
             "informant": 2, "rival": 3, "enemy": 4, "stranger": 3}
START_TRUST = {"enemy": 0.0, "family": 3.0, "partner": 3.0}
UNPROMPTED_GAP = 4


def phone_of(session: Session, player_id: str) -> dict:
    return session.phone.setdefault(player_id, {"turn": 0, "last_unprompted": -99, "contacts": {}, "threads": {}})


def add_contact(session, player_id, name, role="stranger", *, pace=0, close=False) -> dict:
    p = phone_of(session, player_id)
    if name not in p["contacts"]:
        p["contacts"][name] = {"name": name, "role": role, "trust": START_TRUST.get(role, 2.0), "pace": pace,
                               "close": close, "knows": [], "cold_until": -1}
        p["threads"].setdefault(name, [])
    return p["contacts"][name]


def delay(contact: dict) -> int:
    raw = ROLE_BASE[contact["role"]] + (5 - int(contact["trust"])) + contact["pace"]
    return max(0, min(6, raw))


def tone(contact: dict, turn: int) -> str:
    if turn < contact["cold_until"]:
        return "guarded"
    return {5: "warm", 4: "warm", 3: "friendly", 2: "curt", 1: "guarded"}.get(int(contact["trust"]), "hostile")


def change_trust(contact: dict, delta: float) -> None:
    trust = contact["trust"] + delta
    if 0 < delta < 1 and trust > 3:
        trust = max(contact["trust"], 3.0)  # small gains don't climb past friendly
    contact["trust"] = max(0.0, min(5.0, trust))


def post(session, player_id, contact_name, sender, text, deliver_at) -> dict:
    p = phone_of(session, player_id)
    msg = {"sender": sender, "text": text, "turn": p["turn"], "deliver_at": deliver_at, "read": sender == "me"}
    p["threads"].setdefault(contact_name, []).append(msg)
    return msg


def advance(session, player_id) -> list[dict]:
    p = phone_of(session, player_id)
    p["turn"] += 1
    return [m for msgs in p["threads"].values() for m in msgs if m["deliver_at"] == p["turn"] and m["text"] is None]


def may_text_first(session, player_id) -> bool:
    p = phone_of(session, player_id)
    return p["turn"] - p["last_unprompted"] >= UNPROMPTED_GAP


def mark_unprompted(session, player_id) -> None:
    phone_of(session, player_id)["last_unprompted"] = phone_of(session, player_id)["turn"]


def unread(session, player_id) -> dict[str, int]:
    p = phone_of(session, player_id)
    counts = {name: sum(1 for m in msgs if not m["read"] and m["deliver_at"] <= p["turn"] and m["text"])
              for name, msgs in p["threads"].items()}
    return {k: v for k, v in counts.items() if v}
```

### Task 4: Sending a text (server)

**Files:** Modify `server/app.py` (`_handle`), `server/narration.py`; create handler `handle_text` in `server/phone_turns.py`; test `tests/test_phone_turns.py`, `tests/test_app.py`.

**Consumes:** Tasks 1-3. **Produces:** client message `{"type": "text", "to": str, "text": str}`; `async def handle_text(session, client, player_id, message)`; `async def deliver_due(session, client, player_id)`.

- `handle_text`: refuse an unknown contact (`ValueError("not in your contacts")`) and empty or >500-char text. Post the player's message (`sender="me"`, delivered now), append the words to `contact["knows"]` (keep the last 20), add a world event `"{name} quietly texts someone on their phone."` (no words), compute `d = delay(contact)`; an enemy below trust 1 posts nothing; `d == 0` writes the reply now (`write_reply`) and posts it; else posts a placeholder `{"sender": name, "text": None, "deliver_at": turn + d}`. Then `deliver_due`.
- `deliver_due`: for each placeholder from `advance` (and any already due), fill `text` via `write_reply` with the tone at that moment.
- Every `action` and `roll` also calls `deliver_due` after the turn (in `_handle`, inside the session lock).
- `_handle` routes `"text"` to `handle_text`. Texting is allowed while a roll is pending.
- Tests: a text to a partner at trust 5 is answered at once; a creditor's reply arrives after 3 more turns, not before; the shared log never contains the words; the world event is queued; an unknown contact is refused; a failing reply writer still posts the fallback.
- Commit `feat: send texts; replies arrive on the contact's schedule`.
