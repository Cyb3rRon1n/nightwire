# Nightwire

A cyberpunk tabletop RPG with an AI game master — playable solo or with friends, in a browser. Real rules, real dice, a homebrew ruleset built for this project.

Sibling project to [`oracle`](https://github.com/Cyb3rRon1n/oracle) (a D&D-flavored AI-DM), built fresh rather than adapted — see `ROADMAP.md` for why, and for the full phased plan.

**Status**: early planning. Nothing runnable yet — see `ROADMAP.md`'s Phases section.
